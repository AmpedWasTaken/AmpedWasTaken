## About Me

I'm **Amped** — a developer focused on building automation tools, OSINT frameworks, security scanners, and backend systems. My work revolves around practical, high-performance tooling for data gathering, network analysis, and system automation — mostly in **Go**, **JavaScript**, and **Python**.

I prefer building from scratch, optimizing performance, and designing tools that solve real technical problems in cybersecurity, infrastructure, and automation workflows. Security tooling I build is for **ethical and research purposes**.
